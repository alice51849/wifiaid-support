How to run a Wi-Fi diagnostic

  1. Run a Check: test Wi-Fi, DNS and internet in one tap and get a verdict in seconds.
  2. Only one site won't load? Use Check a Website to see whether that one site is down or your whole connection is failing.
  3. Looks connected but keeps lagging? Deep Check collects more stability samples to pin down problems that come and go.
  4. See where it breaks: the full evidence shows DNS, TCP, TLS, TTFB, HTTP, direct IP, IPv4 and IPv6, item by item.
  5. On mesh Wi-Fi: see which node you are on and whether you roamed since your last check.

Keep a record before you call your provider

Check History lets you compare past results, and it is stored only on this device. You can also run a check from Apple Watch, see connection status in a Home Screen widget, or use the full iPad layout.
